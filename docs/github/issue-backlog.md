# GitHub Issue Backlog

이 문서는 첫 주 개발을 위한 이슈 초안입니다. GitHub Issues에 옮길 때는 각 제목을 이슈 제목으로 사용하고, 담당자와 브랜치명을 본문에 포함합니다.

## [FE] 권역 선택 화면 구현

담당: 프론트엔드  
브랜치: `feature/region-selector`

### 작업 내용

- 강릉, 고성/속초, 양양, 동해, 삼척 카드 표시
- 권역별 대표 키워드 표시
- 권역 선택 후 `/survey`로 이동

### 완료 기준

- 모바일/데스크톱에서 카드 레이아웃이 깨지지 않는다.
- 선택한 권역값을 다음 단계에서 사용할 수 있는 구조다.

## [MAP] 카카오 지도 컴포넌트 구조 구현

담당: 지도/데이터  
브랜치: `feature/kakao-map`

### 작업 내용

- 장소 배열 기반 마커 표시 구조 설계

### 완료 기준

- 장소 배열만 넘기면 지도 표시를 붙일 수 있는 구조다.
