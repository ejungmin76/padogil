# 팀원별 작업 파일 안내

팀원 3명이 각자 AI를 사용할 것을 전제로, 역할별 작업 지시 파일을 분리했습니다.

## 읽는 순서

모든 팀원은 먼저 아래 공통 파일을 읽습니다.

1. `docs/team/common-rules.md`
2. `docs/product/user-flow.md`
3. `docs/product/mvp-scope.md`
4. `docs/tech/file-structure.md`

그 다음 본인 역할 파일만 읽고 작업하면 됩니다.

## 역할별 파일

- 프론트엔드 담당: `docs/team/frontend-ai-brief.md`
- 백엔드/API 담당: `docs/team/backend-ai-brief.md`
- 지도/데이터 담당: `docs/team/map-data-ai-brief.md`

## PM 담당

PM은 `docs/pm/kickoff-plan.md`와 `docs/github/issue-backlog.md`를 기준으로 전체 진행을 관리합니다.

## 운영 방식

- 각자 맡은 파일과 화면/API만 우선 작업합니다.
- 작업 전 GitHub Issue를 하나 선택합니다.
- 브랜치는 `feature/기능명` 형식으로 만듭니다.
- PR에는 작업한 화면/API, 확인 방법, 남은 TODO를 적습니다.
- AI가 만든 코드는 그대로 믿지 말고 직접 실행 또는 화면 확인 후 올립니다.
