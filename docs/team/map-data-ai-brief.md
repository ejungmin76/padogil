# 지도/데이터 담당 AI 작업 지시서

## 담당 목표

카카오 지도 연동과 장소 데이터 품질을 담당합니다. 추천 코스가 실제 여행 동선처럼 보이도록 좌표, 지도 표시, 장소 검수 기준을 준비합니다.

## 우선 작업

1. 카카오 지도 컴포넌트 설계
2. 장소 마커 표시 구조 구현
3. 코스 상세에서 장소 순서와 좌표 표시 지원
4. 권역별 샘플 장소 데이터 검수
5. 펫프렌들리 여부 표시 기준 정리

## 주로 수정할 파일

```txt
components/map/
components/course/
types/place.ts
types/course.ts
lib/tourapi/regions.ts
docs/product/user-flow.md
```

## 필요 시 협의 후 수정할 파일

```txt
app/courses/

```

프론트엔드 담당과 화면 파일 충돌이 생길 수 있으므로, 큰 수정 전에는 Issue나 PR 코멘트로 먼저 공유합니다.

## 지도 요구사항

- 카카오 지도 API 키는 `NEXT_PUBLIC_KAKAO_MAP_KEY`를 사용합니다.
- 지도 컴포넌트는 장소 배열을 받아 마커를 표시합니다.
- 코스 상세에서는 장소 순서를 지도와 리스트에서 함께 보여줍니다.
- 지도 API가 아직 연결되지 않아도 placeholder가 깨지지 않아야 합니다.

## 데이터 품질 체크

장소 데이터에는 가능하면 아래 항목이 있어야 합니다.

- 장소명
- 카테고리
- 주소
- 위도/경도
- 대표 이미지
- 태그
- 반려동물 가능 여부

## 권역별 검수 포인트

### 강릉

- 커피거리, 경포해변, 정동진, 오죽헌 중심
- 커플/감성 여행 태그 확인

### 고성/속초

- 설악산, 청초호, 영금정, 통일전망대 중심
- 가족/자연/역사 태그 확인

### 양양

- 서핑, 인구해변, 하조대, 낙산사 중심
- 10~20대/액티비티 태그 확인

### 동해

- 묵호항, 논골담길, 망상해변, 천곡동굴 중심
- 사진여행/로컬 태그 확인

### 삼척

- 장호항, 해양레일바이크, 대금굴 중심
- 가족/액티비티/비경 태그 확인

## 완료 기준

- 지도 컴포넌트 인터페이스가 명확합니다.
- 장소 배열만 넘기면 지도 표시가 가능하도록 설계합니다.
- 좌표가 없는 장소에 대한 fallback UI가 있습니다.
- 코스 상세 화면에 붙이기 쉬운 구조입니다.
- 샘플 장소 데이터 검수 기준이 문서화됩니다.
