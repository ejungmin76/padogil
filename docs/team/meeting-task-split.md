

## 회의에서 공유할 말

팀원들도 AI를 사용할 예정이므로, 작업을 역할별 파일로 나눴습니다. 각자 본인 파일을 AI에게 주고 작업하면 충돌을 줄일 수 있습니다.

## 역할 분배

| 역할 | 담당 범위 | 파일 |
| --- | --- | --- |
| PM | 일정, MVP, 이슈, 회의록 | `docs/pm/kickoff-plan.md` |
| 프론트엔드 | 권역 선택, 설문, 추천 결과 UI | `docs/team/frontend-ai-brief.md` |
| 백엔드/API | 관광공사 API, 추천 API, Supabase | `docs/team/backend-ai-brief.md` |
| 지도/데이터 | 카카오 지도, 장소 검수, 좌표 | `docs/team/map-data-ai-brief.md` |

## 첫 주 작업 순서

1. 프론트엔드 담당은 더미 데이터로 전체 화면 흐름을 만듭니다.
2. 백엔드/API 담당은 관광공사 API 응답을 내부 타입으로 변환합니다.
3. 지도/데이터 담당은 지도 컴포넌트와 장소 표시 기준을 만듭니다.
4. PM은 작업 진행을 GitHub Issue 기준으로 관리합니다.

## 충돌 방지 규칙

- 프론트엔드 담당은 `app/api`, `lib/tourapi`를 수정하지 않습니다.
- 백엔드/API 담당은 `app/page.tsx`, `app/survey`, `app/courses`, CSS를 수정하지 않습니다.
- 지도/데이터 담당은 지도 컴포넌트와 타입 중심으로 작업합니다.
- 공통 타입을 바꿔야 하면 먼저 팀 채팅 또는 Issue에 남깁니다.

## 첫 주 데모 목표

- 권역 선택에서 설문으로 이동
- 설문 완료 후 추천 결과 2~3개 표시
- 코스 상세 화면에서 장소 순서 확인
- 관광공사 API 호출 테스트 결과 확인
- 지도 영역 placeholder 또는 실제 지도 확인
