# MVP 범위

## MVP 목표

심사위원이 핵심 가치를 빠르게 이해할 수 있도록, "설문을 통해 관광공사 API 기반 맞춤 코스가 생성된다"는 경험을 완성한다.

## 반드시 포함

- 강원 동해안 권역 선택
- 4단계 여행 조건 설문
- 한국관광공사 OpenAPI 연동
- 관광지, 음식점, 숙박, 레포츠 데이터 분류
- 반려동물 동반 조건 필터
- 추천 코스 2~3개 카드 표시
- 코스 상세 화면
- 코스 상세의 지도 영역 또는 카카오 지도 placeholder
- 해시태그 기반 장소 탐색
- Vercel 배포

## 가능하면 포함

- 카카오 지도 내 실제 장소 마커 표시
- Supabase에 사용자 설문 결과 저장
- 찜 목록
- 추천 코스 공유 링크

## MVP에서 제외해도 되는 것

- 회원가입/로그인
- AI 추천 고도화
- 리뷰 작성
- 실시간 혼잡도
- 날씨 기반 추천
- 강원도 전역 확장

## 발표/시연 전략

처음부터 모든 권역을 완벽하게 구현하기보다, 한 권역을 완성도 높게 보여주고 나머지 권역은 동일 구조로 확장 가능함을 보여준다.

추천 시연 권역:

- 양양: 서핑, 청년여행, 액티비티 특성이 명확함
- 강릉: 인지도 높고 코스 이해가 쉬움
- 삼척: 지역 분산 효과와 차별성이 잘 보임
