# 사용자 흐름

## 핵심 여정

1. 사용자는 파도길에 접속한다.
2. 강원 동해안 권역을 선택한다.
3. 여행 조건 설문에 답한다.
4. 2~3개의 추천 코스를 비교한다.
5. 원하는 코스를 열어 상세 장소와 지도 동선을 확인한다.
6. 코스 카드의 해시태그를 눌러 관련 장소를 더 탐색한다.

## 화면 구조

### 1. 권역 선택

목표: 사용자가 여행 시작 지역을 빠르게 고른다.

필수 요소:

- 강릉
- 고성/속초
- 양양
- 동해
- 삼척
- 권역별 대표 키워드
- 권역별 대표 이미지 또는 지도 UI

권역 태그 예시:

- 강릉: 커피거리, 해변, 오션뷰, 문화
- 고성/속초: 설악산, 청초호, 가족여행, 역사
- 양양: 서핑, 힙한 감성, 청년여행
- 동해: 묵호항, 논골담길, 사진여행
- 삼척: 해양레일바이크, 동굴, 비경

### 2. 여행 조건 설문

목표: 추천 코스 생성을 위한 최소 조건을 수집한다.

설문 단계:

1. 동반 인원
   - 1인
   - 2인/커플
   - 가족/어린이 포함
   - 단체/4인 이상

2. 이동수단
   - 자차 있음
   - 대중교통 이용
   - 렌터카 이용

3. 반려동물 동반
   - 동반 없음
   - 소형견 동반
   - 대형견 동반

4. 연령대
   - 10~20대
   - 30대
   - 40대
   - 50대 이상

### 3. 추천 코스 결과

목표: 사용자가 여러 코스를 비교하고 선택한다.

필수 요소:

- 추천 코스 2~3개
- 코스 성격 해시태그
- 예상 여행 스타일
- 주요 장소 3~5개
- 반려동물 가능 여부
- 이동수단 적합성
- 지도 보기 버튼

코스 카드 예시:

- `#오션뷰 #카페 #커플`
- `#펫프렌들리 #산책 #해변`
- `#액티비티 #서핑 #청년여행`

### 4. 코스 상세

목표: 사용자가 실제 여행에 필요한 정보를 확인한다.

필수 요소:

- 장소별 순서
- 장소 이름, 이미지, 소개
- 주소, 좌표
- 운영시간
- 주차 여부
- 반려동물 가능 여부
- 지도 영역 또는 카카오 지도 placeholder

가능하면 포함:

- 카카오 지도 실제 마커 표시

### 5. 해시태그 탐색

목표: 추천 코스 밖의 장소도 자유롭게 발견한다.

필수 요소:

- 선택한 해시태그와 관련된 장소 목록
- 관광지, 음식점, 숙박, 레포츠 필터
- 권역 필터
- 펫프렌들리 필터

## 추천 로직 1차 기준

1. 권역으로 장소 후보를 제한한다.
2. contentTypeId로 관광지, 음식점, 숙박, 레포츠를 분류한다.
3. 반려동물 동반이면 반려동물 동반여행 API 데이터를 우선 사용한다.
4. 이동수단이 대중교통이면 접근성이 좋은 장소를 우선한다.
5. 연령대와 동반 인원에 따라 태그 가중치를 다르게 둔다.
6. 연관 관광지 API로 주변 장소를 묶어 코스를 만든다.
